# Heyhye 블로그 도우미

메모와 사진을 넣으면 Claude가 네이버 블로그 초안을 쓰고, 크롬 글쓰기 화면까지 자동으로 채워 줍니다.
**발행 버튼은 사람이 누릅니다.** 자동 발행은 네이버 약관 위반이고 저품질 판정 위험이 커서 일부러 뺐습니다.

## 흐름

```
notes/메모.md + photos/사진들
        │  npm run draft      (Claude API)
        ▼
drafts/2026-10-28-메모.json
        │  npm run fill       (크롬 자동 입력)
        ▼
네이버 글쓰기 화면에 제목·본문·사진·태그가 채워진 상태  →  읽고 고치고 직접 [발행]
```

## 처음 한 번 설정 (맥)

1. Node.js 20 이상 설치: https://nodejs.org
2. 터미널에서

```bash
cd Heyhye
npm install
cp .env.example .env
```

3. `.env` 파일을 열어 API 키, 블로그 아이디, 스마트스토어 주소, 브랜드 이름을 채웁니다.
4. 네이버 로그인 (전용 크롬 프로필에 저장됩니다. 평소 쓰는 크롬과는 별개입니다)

```bash
npm run login
```

## 매번 쓰는 법

1. `notes/` 에 오늘 메모를 `.md` 파일로 저장합니다. 세 줄이면 충분합니다. (`notes/example.md` 참고)
2. `photos/` 에 올릴 사진을 넣습니다. 파일 이름 순서대로 본문에 들어갑니다. 지난번 사진은 지워 주세요.
3. 실행

```bash
npm run post
```

초안이 터미널에 먼저 출력되고, 이어서 크롬이 열리며 글쓰기 화면이 채워집니다.
마음에 안 들면 `npm run draft` 만 다시 돌려 초안을 새로 만든 뒤 `npm run fill` 을 실행하세요.

## 말투 맞추기

`samples/` 폴더에 예전에 쓴 글을 `.txt` 로 몇 편 넣어 두면 그 말투를 따라 씁니다.

## 자주 생기는 문제

- **에디터 자동 입력 실패**: 네이버가 에디터 구조를 바꾸면 생깁니다. 이때는 초안이 클립보드에 복사되니 본문에 Cmd+V 로 붙여 넣고 사진만 직접 올리면 됩니다. `src/fill.js` 의 선택자(selector)를 고치면 다시 자동화됩니다.
- **로그인 풀림**: `npm run login` 을 다시 실행합니다.
- **하루 1편 이내**로 올리는 것을 권합니다. 같은 시간에 기계적으로 올라가는 글은 저품질 신호가 됩니다.

## 비용

초안 1편에 Claude API 비용이 사진 수에 따라 약 50~150원 정도 듭니다.
